# 🐾 WorkBuddy 福利小雷达

> 叮～你的积分是不是又双叒忘领了？别急，这只小雷达每天帮你把散落各处的福利翻出来，摆成一张清清爽爽的清单。看一眼就知道今天还能领啥、哪些快过期——再也不用满世界找入口啦。

## 它能干嘛

- 🧭 **福利地图**：客户端 Buddy 加油站、成长计划连登、任务中心、猫猫旅行、抽奖盲盒、官网活动……能领的、要真人认证的、快过期的，一次给你说明白。
- 🔔 **贴心提醒**：积分按月清零？月底最后 3 天它会加粗喊你一声。
- 🐱 **默认只动嘴不动手**：一般问法下它只查只报，绝不乱点你的鼠标。

## 两种模式，你说了算

| 怎么说 | 它怎么动 |
|---|---|
| 「有哪些福利」「查下积分」「今天能领啥」 | **只读巡逻**——只列清单和入口，不做任何点击 |
| 「帮我领」「替我签到」「一键领取」 | **代领模式**——这才动手去点那几下 |

拿不准它会按只读处理，还会奶声奶气提醒你：「想让我直接领的话，说声『帮我领』就行～」

## 装哪儿

把整个目录放到 `~/.workbuddy/skills/workbuddy-benefits-patrol/`，或者在 WorkBuddy 里通过技能安装入口导入同名目录。

用的时候随口一句「WorkBuddy 签到」「有哪些福利可以领」「帮我看看积分」就成。

## 需要啥

- 浏览器控制能力（查网页端成长计划、任务中心）——没有就只报网页部分，不假装领了。
- Windows 本机 GUI 自动化能力（点客户端加油站签到）——没有就把这一项列成"手动领取"。
- 你自己已经登录 WorkBuddy。它**不碰**账号密码、验证码，登录这事只认你本人。

## 关于"这是不是薅羊毛"

真不是。领的是平台明明白白摆在那儿、一人一天一次的每日赠送积分，不是钻漏洞、不是批量养号、不是虚假交易。这个技能的主体是**帮你查清楚有哪些福利**，自动代领只是一个默认关闭、要你亲口同意才开的小开关。

## 几句正经话（但很短）

- 只服务你自己的账号，每日一次；不做多账号批量、不伪造行为、不逆向接口。
- 不读本地凭据、不调内部接口——这两条是铁律。
- 数值和入口以当期页面为准，本技能里的清单可能过期，仅作线索。
- 遵守 WorkBuddy 服务协议；平台要是改了规矩或明确不让自动化了，它就乖乖改成只提示、不动手。
- 用不用、怎么用的最终判断权和风险，在你自己手里。
